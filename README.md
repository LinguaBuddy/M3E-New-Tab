## ✨ Features

- **🎨 Dynamic Material You Color Palettes:** Choose from 10+ gorgeous accent color dots that instantly transform your UI buttons, borders, and ripples.
- **🌙 Seamless Dark & Light Mode:** Fully adaptive theming with smooth transitions.
- **⚡ Google Ripple Effects:** Authentic Material Design tactile click feedback on every interactive element.
- **🔍 Universal Search Integration:** Switch your default search provider instantly (Google, DuckDuckGo, Bing, Brave Search).
- **⏱️ Live Custom Clock:** Supports both 12-hour and 24-hour formats right in your top bar.
- **⚙️ Deep Customization Settings:** Toggle animations, glassmorphism surface elevations, shortcuts bars, and Google branding seamlessly.
- **🚀 Zero Bloat:** Pure, native JavaScript and CSS. No heavy frameworks, lightning-fast load times.
